    Database Schema Reference (go-flowAPI v1.3.2)

    go-flowAPI (v1.3.2) does not auto-migrate tables at startup. Provision the 12 required tables (7 core artifact/telemetry/user tables + 5 granular group & pipeline ACL tables) in your target database using the DDL scripts below before starting the API.

    Adjustable Schema & Table Constants (tables.go)

    All table and schema paths are controlled via constants in tables.go:

    Constant Default Value Description
    DefaultSchema "dbo." Default schema prefix (adjusted or stripped automatically for SQLite/MySQL/Oracle)
    TablePipelineContent DefaultSchema + "flow_pipeline_content" Stores pipeline XML definitions (Name, Description, PipelineXML)
    TableOptionsContent DefaultSchema + "flow_options_content" Stores reusable CLI/execution option XML profiles (Name, Description, OptionsXML)
    TableConfigContent DefaultSchema + "flow_config_content" Stores reusable <Configuration> XML profiles (Name, Description, ConfigXML)
    TablePipelineRuns DefaultSchema + "pipeline_runs" Stores high-level pipeline execution run summaries
    TablePipelineEvents DefaultSchema + "pipeline_events" Stores per-node execution events and node_output
    TableAPIAuditEvents DefaultSchema + "flow_api_events" Stores API-level audit logs for all CRUD, upload, auth, and execution calls
    TableAPIUsers DefaultSchema + "flow_api_users" Stores BasicAuth credentials and role permissions (scoped, execution-only, read-only, write/upload, all)
    TableAPIGroups DefaultSchema + "flow_api_groups" Stores API user groups (name, description)
    TableAPIUserGroups DefaultSchema + "flow_api_user_groups" Many-to-many mapping of API users to API user groups (group_name, username)
    TablePipelineGroups DefaultSchema + "flow_pipeline_groups" Stores logical pipeline groups (name, description, optional name_pattern glob)
    TablePipelineGroupMembers DefaultSchema + "flow_pipeline_group_members" Many-to-many mapping of pipelines to pipeline groups (group_name, pipeline_name)
    TablePipelineACL DefaultSchema + "flow_pipeline_acl" Granular user/group allow/deny ACL rules (create, read, update, delete, execute, all) per pipeline, pipeline group, or *

    -- 1. Pipeline Content Table (compatible with go-flow & db_importer)
IF OBJECT_ID('dbo.flow_pipeline_content', 'U') IS NULL
CREATE TABLE dbo.flow_pipeline_content (
    ID          INT IDENTITY(1,1) PRIMARY KEY,
    Name        NVARCHAR(255) NOT NULL UNIQUE,
    Description NVARCHAR(MAX) NULL,
    PipelineXML NVARCHAR(MAX) NULL,
    CreatedAt   DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME(),
    UpdatedAt   DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME()
);

-- 2. Options Content Table (compatible with go-flow & db_importer)

    occurred_at   DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME(),
    event_type    NVARCHAR(128) NOT NULL,
    http_method   NVARCHAR(16)  NOT NULL,
    path          NVARCHAR(512) NOT NULL,
    artifact_type NVARCHAR(64)  NULL,
    artifact_name NVARCHAR(255) NULL,
    run_id        NVARCHAR(64)  NULL,
    auth_user     NVARCHAR(255) NULL,
    remote_addr   NVARCHAR(128) NULL,
    status_code   INT           NOT NULL,

    duration_ms   BIGINT        NOT NULL,

-- 7. API BasicAuth Users & Permissions Table
IF OBJECT_ID('dbo.flow_api_users', 'U') IS NULL
CREATE TABLE dbo.flow_api_users (
    username      NVARCHAR(255) NOT NULL PRIMARY KEY,
    password_hash NVARCHAR(512) NOT NULL,
    permission    NVARCHAR(128) NOT NULL, -- 'scoped', 'execution-only', 'read-only', 'write', 'upload', 'all' (or comma-separated)
    is_active     BIT           NOT NULL DEFAULT 1,
    description   NVARCHAR(512) NULL,
    created_at    DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME(),
    updated_at    DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME()
);

-- 8. API User Groups Table
IF OBJECT_ID('dbo.flow_api_groups', 'U') IS NULL
CREATE TABLE dbo.flow_api_groups (
    id          INT IDENTITY(1,1) NOT NULL PRIMARY KEY,
    name        NVARCHAR(128)     NOT NULL CONSTRAINT UQ_flow_api_groups_name UNIQUE,
    description NVARCHAR(512)     NULL,
    created_at  DATETIME2         NOT NULL DEFAULT SYSUTCDATETIME(),
    updated_at  DATETIME2         NOT NULL DEFAULT SYSUTCDATETIME()
);

-- 9. API User <-> Group Membership Table
IF OBJECT_ID('dbo.flow_api_user_groups', 'U') IS NULL
CREATE TABLE dbo.flow_api_user_groups (
    group_name NVARCHAR(128) NOT NULL,
    username   NVARCHAR(255) NOT NULL,
    created_at DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME(),
    CONSTRAINT PK_flow_api_user_groups PRIMARY KEY CLUSTERED (group_name, username)
);

-- 10. Pipeline Groups Table
IF OBJECT_ID('dbo.flow_pipeline_groups', 'U') IS NULL
CREATE TABLE dbo.flow_pipeline_groups (
    id           INT IDENTITY(1,1) NOT NULL PRIMARY KEY,
    name         NVARCHAR(128)     NOT NULL CONSTRAINT UQ_flow_pipeline_groups_name UNIQUE,
    description  NVARCHAR(512)     NULL,
    name_pattern NVARCHAR(255)     NULL,
    created_at   DATETIME2         NOT NULL DEFAULT SYSUTCDATETIME(),
    updated_at   DATETIME2         NOT NULL DEFAULT SYSUTCDATETIME()
);

-- 11. Pipeline <-> Pipeline Group Membership Table
IF OBJECT_ID('dbo.flow_pipeline_group_members', 'U') IS NULL
CREATE TABLE dbo.flow_pipeline_group_members (
    group_name    NVARCHAR(128) NOT NULL,
    pipeline_name NVARCHAR(255) NOT NULL,
    created_at    DATETIME2     NOT NULL DEFAULT SYSUTCDATETIME(),
    CONSTRAINT PK_flow_pipeline_group_members PRIMARY KEY CLUSTERED (group_name, pipeline_name)
);

-- 12. Granular Pipeline & Pipeline-Group ACL Rules Table
IF OBJECT_ID('dbo.flow_pipeline_acl', 'U') IS NULL
CREATE TABLE dbo.flow_pipeline_acl (
    id             INT IDENTITY(1,1) NOT NULL PRIMARY KEY,
    principal_type NVARCHAR(32)      NOT NULL, -- 'user' | 'group'
    principal_name NVARCHAR(255)     NOT NULL,
    target_type    NVARCHAR(32)      NOT NULL, -- 'pipeline' | 'pipeline_group' | '*'
    target_name    NVARCHAR(255)     NOT NULL,
    permissions    NVARCHAR(128)     NOT NULL, -- 'create,read,update,delete,execute' or 'all'
    effect         NVARCHAR(16)      NOT NULL CONSTRAINT DF_flow_pipeline_acl_effect DEFAULT N'allow',
    description    NVARCHAR(512)     NULL,
    created_at     DATETIME2         NOT NULL DEFAULT SYSUTCDATETIME(),
    updated_at     DATETIME2         NOT NULL DEFAULT SYSUTCDATETIME(),
    CONSTRAINT CK_flow_pipeline_acl_principal_type CHECK (principal_type IN (N'user', N'group')),
    CONSTRAINT CK_flow_pipeline_acl_target_type    CHECK (target_type IN (N'pipeline', N'pipeline_group', N'*')),
    CONSTRAINT CK_flow_pipeline_acl_effect         CHECK (effect IN (N'allow', N'deny')),
    CONSTRAINT UQ_flow_pipeline_acl_rule           UNIQUE NONCLUSTERED (principal_type, principal_name, target_type, target_name, effect)
);

    Seeding Initial BasicAuth Users, Groups & Granular Pipeline ACLs

    flow_api_users.password_hash supports: 1. bcrypt hashes ($2a$... or $2b$...) — recommended for production, and automatically generated when creating users via POST /api/v1/users. 2. SHA-256 hex hashes prefixed with sha256: (e.g., sha256:5e884898da28047151d0e56f8dc6292773603d0d6aabbdd62a11ef721d1542d8). 3. Plaintext (evaluated with constant-time SHA-256 digest comparison; convenient for quick bootstrap in a dev database).

    Supported Permission Values (permission column)

    Permission Value Allowed Operations
    scoped (Recommended default) Zero global permissions — strictly governed by granular allow / deny rules in flow_pipeline_acl (user-level or group-level across individual pipelines, pipeline groups, or *)
    execution-only Non-pipeline read/crypto/logs (options, configs, /runs, /events, /audit, /crypto/*), plus pipeline read & execute when granted via flow_pipeline_acl (or globally only if -strict-acl=false)
    read-only Non-pipeline read/crypto/logs, plus pipeline read when granted via flow_pipeline_acl (or globally only if -strict-acl=false)
    write or upload options & configs CRUD/upload, plus pipeline create/read/update/delete when granted via flow_pipeline_acl (or globally only if -strict-acl=false)
    all Full administrator access to all endpoints (Read, Write/Upload, Execute, /api/v1/db/test, /api/v1/users, /api/v1/groups, /api/v1/pipeline-groups, /api/v1/acls, /api/v1/permissions/effective)

    Default Strict Pipeline ACLs (-strict-acl=true / FLOW_API_STRICT_ACL=true by default): By default in v1.3.1, all non-admin (non-"all") accounts have no access to pipelines unless granted via explicit allow rules in flow_pipeline_acl (with explicit deny overriding allow). Set -strict-acl=false (FLOW_API_STRICT_ACL=false) only if you want legacy global-role fallback on pipelines without ACLs.
